# AGENTS.md

This file holds this project's instructions for coding agents. `CLAUDE.md` contains
only the line `@AGENTS.md`, which imports this file, so every agent reads the same text.

Treat this file as you would `CLAUDE.md`. Whenever you would add or change project
instructions or project memory in `CLAUDE.md` (running `/init`, being asked to remember
something about the project, recording a convention or a command), make that edit here
instead. Leave `CLAUDE.md` as the single import line.
